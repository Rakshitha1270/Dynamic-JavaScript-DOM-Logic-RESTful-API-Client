# Dynamic JavaScript DOM Logic & RESTful API Client

A responsive product explorer built with modern JavaScript (ES6+), asynchronous REST API integration, dynamic DOM manipulation, client-side filtering, sorting, localStorage caching, loading states, error handling, and light/dark theme support.

## 🚀 Project Overview

This project demonstrates how to build a dynamic web application that communicates with a public REST API and updates the user interface without full-page reloads.

The application fetches product data from the DummyJSON REST API and provides an interactive interface for exploring, searching, filtering, and sorting products.

## ✨ Features

- 🌐 REST API integration using `fetch()`
- ⚡ Asynchronous JavaScript using `async/await`
- 🔎 Real-time product search
- 🗂️ Category-based filtering
- ↕️ Dynamic sorting by title and price
- 🔄 Refresh data from the API
- 💾 Client-side state persistence using `localStorage`
- 🌙 Light and dark theme support
- ⏳ Loading and skeleton states
- ⚠️ User-friendly error handling
- 📭 Empty search result state
- 🖥️ Responsive product grid
- ♿ Accessible focus states and semantic UI structure
- 🧩 Modular JavaScript using ES modules
- 🚫 No full-page reload during filtering or sorting
